**Skill tool scope gate** — `@skill.tool(..., scopes=(...))` enforces
`AuthSpec(scopes=...)` via `enforce_auth` before the handler body. Scope denial
is mapped from `HTTPError(403)` to `ToolAuthError`; MCP `tools/call` turns that
into a JSON-RPC error and `authz.scope.denied` is audited. Declare scopes with
`app.register_scope`.
