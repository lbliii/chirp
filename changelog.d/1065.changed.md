**MCP protocol version negotiation (`2025-06-18`)** — ``initialize`` now
echoes a supported client ``params.protocolVersion`` (``2026-07-28``,
``2025-06-18``, ``2025-03-26``, ``2024-11-05``) instead of always advertising
``2026-07-28``. Standard ``2025-06-18`` clients (Cursor, Claude Code, …) no
longer receive ``chirp/legacyOfframp`` metadata or spurious ``HeaderMismatch``
(``-32020``) on header-less ``tools/list`` / ``tools/call``. SEP-2243 routing
headers remain required only for ``2026-07-28+`` advertisements;
``server/discover`` lists the full ``supportedVersions`` set.
