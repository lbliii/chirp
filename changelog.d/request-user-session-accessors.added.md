Request now exposes ergonomic request-scoped auth and session accessors, and templates get a session-safe `session()` global. `request.user` returns the current user (or `AnonymousUser`) and never raises, mirroring `current_user()`. `request.session` returns the session dict and raises `LookupError` when `SessionMiddleware` is absent, mirroring `get_session()`'s fail-loud contract — so `request.session.get("x")` works without a `None` footgun. In templates, `session()` returns the live session dict when `SessionMiddleware` is active or an empty read-only mapping otherwise (never raises), and is auto-registered as a template global only when `SessionMiddleware` is present.
