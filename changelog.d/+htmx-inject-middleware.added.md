**`AppConfig(htmx=True)` provisions htmx for you.** Chirp now injects the htmx core script before `</body>` on buffered full-page HTML and rewrites `StreamingResponse` shells (e.g. `Suspense`) the same way, mirroring the Alpine injector. It uses the proven unpkg browser build (`htmx.org@2.0.4`) and emits a `data-chirp="htmx"` marker. Dedup is robust: injection is skipped when a page already carries the marker **or** any htmx `<script src="…htmx…">` (a marker-less hand-provisioned or third-party script), so a scaffolded chirpui app that later opts into `htmx=True` is never double-loaded. Set `htmx_sse=True` to also inject the htmx SSE extension, and `htmx_version` to pin a different core version. The opt-in defaults to off, so existing apps and scaffolds are unaffected.
