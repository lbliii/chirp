**UI-neutral shell actions and hypermedia handoff** — Chirp renders generic shell actions without importing chirp-ui templates. Applications override the HTML renderer via `app.set_shell_actions_renderer(...)` while the OOB transport stays fixed. `use_chirp_ui` adapts to the chirp-ui visual renderer. Provisional handoff helpers (`HypermediaHandoff`, `FocusHandoff`, `TitleHandoff`, `AnnouncementHandoff`, `apply_handoff`) cover focus, title/history, and live-region announcements with a CSP-safe `/_chirp/handoff.js` runtime.
