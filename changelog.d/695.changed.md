PostgreSQL parameterized, prepared, and streamed reads now negotiate text or binary format per result column. Arrays, ranges, composites, intervals, and other registered families decode through proven binary codecs; live server-assigned enum/composite dependencies are discovered per connection. Unknown types retain PostgreSQL text output, while unexpected unsupported binary data raises an actionable protocol error. Code that expected parameterized array/range/composite values to remain wire-format strings should migrate to the typed values.
