**MCP Streamable HTTP routing headers (SEP-2243)** — When a request
advertises a modern protocol version (``MCP-Protocol-Version`` header or
``params._meta``), ``/mcp`` validates ``Mcp-Method`` / ``Mcp-Name`` /
``MCP-Protocol-Version`` against the JSON-RPC body. Missing or mismatched
headers return HTTP 400 with JSON-RPC ``HeaderMismatch`` (``-32020``).
