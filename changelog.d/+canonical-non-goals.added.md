**Canonical Non-Goals doc.** Added `docs/about/non-goals` as the single authoritative list of the bright lines Chirp's core deliberately won't cross — no stateful ORM, no in-core admin/CRUD generator, no in-core email, no background-jobs scheduler, no WebSocket return type (SSE over WebSockets, always), no WSGI / no Python floor below 3.14, no general HTTP rate limiting in core, no in-core telemetry/APM, and no ecosystem absorption — each paired with the honest alternative. Leads with the identity claim that Chirp holds zero per-client server view state. The Philosophy "What Chirp Is Not" section and the PRD "Out of Scope" section now link to it instead of forking the list. Decision wording is pending steward sign-off.
